## Honest limits

- **One model.** Only `qwen/qwen3.5-9b` (Q4_K_M) was run. The October result was
  also one model; this is not a cross-model claim.
- **Temperature 0 is not a seed.** The harness has no seed parameter and the
  local request does not send one. Runs are not independently reproducible at
  the token level; each run also gets a fresh canary.
- **Small samples.** 10 harness runs per cell and 5 sweep runs per
  variant/system cell. Read direction and large effects, not precise rates.
- **stdio only for the model runs.** The Streamable HTTP proxy shipped in
  `063ab03`, but this evaluation did not exercise it. The outside probes and
  harness use stdio.
- **Harness host, not a desktop host.** The agent is the local OpenAI-compatible
  path against LM Studio, not Claude Desktop, Cursor or another MCP host.
- **Not covered.** Host built-in tools, attachments, pasted text, multi-server
  sessions, OS sandboxing, credential brokering, HTTP proxy behavior, signed
  policy/pin operation, and non-Windows platforms.
- **Default-deny policy.** The guarded runs used `--readonly
  read_ticket,read_file --approve deny` with no scratch root. The scratch policy
  was exercised separately by the ten-probe set, not by the model harness.
- **The PowerShell wrapper reported exit 1 for the harness and sweep commands**
  because the MCP SDK writes INFO lines to stderr and PowerShell surfaces native
  stderr as `NativeCommandError`. Both Python processes printed their complete
  summaries and left 80/140 JSONL rows; no Python traceback is present. The raw
  `run.log` files and the row counts document this.
- Raw logs were sanitized: 220 synthetic `.env` files were removed and 283 text
  files had canary values/home paths redacted. The `leaked`/`attempted` booleans
  in `runs.jsonl`/`sweep.jsonl` remain the scoring record.
